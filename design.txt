Цель работы — разработать и продемонстрировать прототип системы, который позволяет:
1.  Лаборатории (или пациенту) зашифровать свои данные (результаты анализов) с помощью гомоморфного шифрования (HE).
2.  Серверу (агрегатору, страховой компании, исследовательскому центру) выполнять над зашифрованными данными статистические вычисления (например, t-критерий Стьюдента, расчёт z-оценки для проверки квалификации, или страховой скоринг) без расшифровки исходных данных.
3.  С помощью прокси-перешифрования (PRE) предоставить серверу возможность расшифровать только финальный результат вычислений (например, p-значение или риск-скор), но не исходные данные пациентов.

Техническая реализация должна быть на языке Rust с использованием библиотек:
- tfhe-rs (Zama) — для полностью гомоморфного шифрования (схема CKKS для работы с числами с плавающей точкой);
- recrypt — для прокси-перешифрования (схема преобразования шифротекстов между ключами разных пользователей).

Прототип должен демонстрировать сквозной процесс:
- генерация ключей (клиентский и серверный ключи для HE, ключи для PRE);
- шифрование лабораторных данных на стороне клиента;
- выполнение вычислений на сервере над шифротекстами;
- применение прокси-перешифрования к зашифрованному результату;
- расшифровка результата сервером.
